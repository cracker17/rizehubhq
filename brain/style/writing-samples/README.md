# Writing samples (Content Writer voice)

Drop **3–5 pieces of your own writing** here so the Content Writer sounds like you, not like generic AI copy.

- Format: `.md` or `.txt`, one piece per file (a blog post, a newsletter, a LinkedIn post, a client email you liked).
- Name them so the best ones sort first, e.g. `01-blog-shopify-speed.md`, `02-newsletter-sept.txt`.
- Keep each one short and typical of how you write: 300–1,500 words is plenty. Longer files are cut to an excerpt.
- Only your own words, or text you have the right to reuse. No client secrets, passwords or private data.

How it is used: before every writing task the worker adds up to 5 samples (about 6,000 characters each, 20,000 in
total, in file-name order) to the Content Writer's task prompt. The writer copies the rhythm, sentence-length mix,
word choice and warmth. It never copies facts or claims from the samples into client work.

This README is never sent to the writer. Empty folder = the writer follows `brain/company/brand-voice.md` only.
