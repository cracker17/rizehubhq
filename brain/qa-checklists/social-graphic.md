# QA checklist: social-graphic
Pass = every check true.

1. **Dimensions** correct per platform/format. Verify: `identify`.
2. **Count** of posts/slides matches brief. Verify: file list.
3. **Copy matches approved captions/on-image text**, 0 typos. Verify: diff.
4. **Safe zones**: story text clear of top 250/bottom 340 px; feed key content within 3:4 grid crop. Verify: overlay guide.
5. **Readable at 375 px** in ≤ 2 s; headline ≥ 56 px on 1080 canvas. Verify: contact sheet.
6. **Contrast ≥ 4.5:1**. Verify: colour sample.
7. **Brand consistency**: brand fonts/colours, consistent logo/handle placement across the set. Verify: contact sheet vs `brand.md`.
8. **Carousel structure**: slide 1 hook, last slide CTA, visual continuity. Verify: sequence.
9. **0 AI artefacts or AI-rendered text**. Verify: inspect at 200%.
10. **No invented claims/stats/testimonials/prices**. Verify: source check.
11. **Alt text** provided for each graphic. Verify: output notes.
12. **Templates (if requested)**: editable slots named, 2 filled examples, usage note with character limits. Verify: files.
13. **Licences + naming convention** present. Verify: output.
14. **criteria_map** complete.
