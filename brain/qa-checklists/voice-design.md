# QA checklist: voice-design
Pass = every check true.

1. **Consent gate**: if any real person's voice is cloned/changed/imitated, written consent confirmed by CEO is referenced; no celebrity/sound-alike. Verify: output + approvals.
2. **Voice spec** complete: personality, accent, pace, pitch, energy, uses, avoid list. Verify: `voice-spec.md`.
3. **Audition pack**: 3–5 candidates rendered with the same test script and settings, labelled. Verify: files.
4. **Test script** covers hook, number/price, brand name, question, CTA, hardest names. Verify: read.
5. **Recommendation** with reasons tied to brand adjectives. Verify: read.
6. **Consistency**: 3 renders of the same line by the chosen voice sound matched (no drift). Verify: listen.
7. **Pronunciation dictionary** covers brand, product, place names. Verify: read + listen to samples.
8. **Settings locked**: provider voice ID and all parameters recorded. Verify: spec.
9. **Samples meet loudness** (−14 LUFS ±1, TP ≤ −1 dBTP). Verify: `ebur128`.
10. **No artefacts** (metallic tone, breaths, mispronunciations). Verify: listen.
11. **criteria_map** complete.
