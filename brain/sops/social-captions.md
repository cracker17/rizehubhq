# SOP: social-captions

Owner: writer. Output: ready-to-approve captions, one block per post, per platform.

## Inputs to confirm
Client, platform(s), post topic or asset description, goal, CTA destination (link, DM keyword, booking), offer terms, handles to tag (with permission), disclosure needs. Missing link or offer → `[PLACEHOLDER: ...]` or `ask_ceo` if blocking.

## Steps
1. Read client `brand.md` (voice, banned words, emoji rules) and 3–5 approved past captions if available.
2. Identify the single job of the post: stop the scroll, teach, prove, sell or start a conversation.
3. Pick the search keyword a buyer would type (e.g. "linen summer dress", "roof leak repair Brisbane"). It must appear naturally in the first 125 characters.
4. Write 3 hook options, choose the strongest, keep the other 2 as alternates.
5. Write the body with the structure below. Short lines. White space. One idea.
6. Add one CTA. Only one.
7. Add hashtags: 3–5 (Instagram/TikTok), 0–3 (LinkedIn), 0–1 topic tag (Threads), 0–2 (Facebook). Mix brand + niche + topic. No banned, generic (#love, #instagood) or unrelated tags.
8. Add alt text for images (what is visible, ≤ 125 characters, no "image of").
9. Vary tone and opening across the batch. Read aloud: remove filler, hype, em-dash chains and AI tells.
10. Self-QA against `brain/qa-checklists/social-captions.md`, then `submit_output`.

## Caption structure
```
HOOK (≤ 12 words, first line)
Value or story (2–5 short lines)
Proof (real review, number or detail from the brief; skip if none)
CTA (one action)
Hashtags
```

## Platform limits and norms
- Instagram: 2,200 chars max; ~125 visible before "more"; aim 80–300 words for carousels, shorter for Reels.
- TikTok: 4,000 chars max; keep 1–3 lines plus keywords; on-screen text carries the message.
- LinkedIn: 3,000 chars; first ~210 chars decide "see more"; 100–250 words typical; link in first comment if brief allows.
- Threads: 500 chars per post; conversational; question endings work.
- Facebook: first ~125 chars visible; local and community framing.
- YouTube Shorts: title ≤ 100 chars with keyword; description 1–2 lines.

## Output template per post
```
Post #: 3 | Platform: Instagram Reel | Pillar: Educate | Keyword: linen dress care
Hook: ...
Caption: ...
CTA: ...
Hashtags: ...
Alt text: ...
Alternates: hook B / hook C
Notes: disclosure needed? placeholders? claims to check?
```

## Compliance
- Sponsored, gifted or affiliate: "#ad" or platform Paid partnership label, at the start, not buried.
- No health, weight, earnings or guaranteed-result claims without proof in the brief.
- Tag people or brands only when the brief confirms permission.
